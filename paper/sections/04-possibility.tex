\section{What is possible}\label{sec:possibility}
% ============================================================================
The impossibility results identify the obstruction precisely: the \emph{choice} of a rate-limited attitude profile. Once
that choice is removed, convexification works again, and in the pure-TVC case it works without any relaxation. This
section collects the positive results. Aumann's theorem \cite{aumann1965} is the one external theorem used without proof.
The Pontryagin maximum principle \cite{pontryagin1962,vinter2000book} enters only as a labelled hypothesis (H-PMP).

\subsection{LCvx is exact for any fixed attitude profile}\label{sec:C}
Fix a measurable $b:[0,t_f]\to\Sph$. The original problem $\mathrm P_0(b;\theta)$ minimizes $\int\norm T$ subject to
$\rho_1\le\norm T\le\rho_2$, $\ip{b}{T}\ge\norm T\cos\delta$, the dynamics \eqref{eq:dyn} and the boundary conditions. The relaxation
$\mathrm P_1(b;\theta)$ minimizes $\int\Gamma$ over $T\in K_\Gamma(b):=\{\norm T\le\Gamma,\ \ip bT\ge\Gamma\cos\delta\}$,
$\rho_1\le\Gamma\le\rho_2$. This is the pointing-cone LCvx of \cite{acikmese2013tcst} with a time-varying axis.

\begin{theorem}[Theorem C-W: value and feasibility exactness for any $b$ {\pnote{math/04 \S3}}]\label{thm:CW}
% CLAIMS: C, C-W (CONFIRMED by verify-pos6; PARTIALLY FORMALIZED), C-F (FORMALIZED under AumannInstance) | Lean: relaxed_subset_original, original_subset_relaxed, origFeas_eq_relFeas (Positive/Convexity.lean; Aumann as hypothesis; constant mass, no state constraints)
For every $\mathrm P_1$-feasible $(T,\Gamma)$ there is a measurable $\tilde T(t)\in\{\norm{\tilde T}=\Gamma,\ \angle(\tilde T,b)\le\delta\}$
with the same $\Gamma$, mass history and cost, whose state agrees with that of $(T,\Gamma)$ at $t_f$ and at any prescribed
finitely many times. Hence $\mathrm P_0$ and $\mathrm P_1$ have the same feasible data and the same value, attainment transfers,
and nodewise state constraints are preserved. With constant mass (or the convexified-mass model),
$F_{t_f}(b)=\{\theta:\mathrm P_0(b;\theta)\text{ feasible}\}$ is convex (Corollary C-F).\Sproved\
\Sleanpart{feasibility part and C-F, constant mass, no state constraints, Aumann as explicit hypothesis}
\end{theorem}
\begin{proof}[Proof idea]
On each subinterval the state increment is linear in $T/m$ for the fixed mass history. The extreme points of the cap
$K_\Gamma(b)$ are exactly its spherical part. Aumann's theorem replaces the relaxed selection by a lossless one with the
same moments.
\end{proof}
With convex path constraints the value statement holds under a uniform Slater condition (a relaxed-feasible trajectory at
positive distance from the constraint boundary at \emph{all} times). Attainment of $\mathrm P_0$ is not claimed in that case.
\emph{Caveat:} such a Slater point cannot exist when a path constraint is active at the fixed touchdown state, as for the
glide-slope cone with apex at the target or for $r_z\ge0$ with $r_z(t_f)=0$, i.e.\ for the standard constraint set
\eqref{eq:X}. For that set the value statement with path constraints is therefore not established; the nodewise statement
is.

\begin{theorem}[Theorem C-S: every relaxed optimum is lossless, under PMP {\pnote{math/04 \S5}}]\label{thm:CS}
% CLAIMS: C-S, C-D (verify-pos6: NEEDS FIX minor, applied here: meagre set in the admissible class; velocity-constraint caveat; PARTIALLY FORMALIZED under PMP hypothesis) | Lean: PMPConclusion.lossless_ae_off_degenerate, min_throttle_of_antiRay, lossy_subset_degenerate_minThrottle, lossless_ae_of_ND (Positive/PMP.lean, Primer.lean; PMP as explicit hypothesis; axioms clean)
Assume (H-PMP) for a $\mathrm P_1$-optimal solution, and let $p=a+ct$ be the (affine, for every $b$) primer vector. Off
$D=\{t:p(t)\in-\R_{\ge0}b(t)\}$ the optimum is lossless and pointwise unique. With constant mass the lossy set is contained in
$D\cap\{\Gamma^*=\rho_1\}$. $D$ has positive measure only if $p\equiv0$, or $b$ dwells at $\pm$ a fixed vector, or $b$ follows a
\emph{gnomonic line} $\pm(a+ct)/\norm{a+ct}$ on a set of positive measure. For analytic $b$, $\det(b,\dot b,\ddot b)\not\equiv0$
suffices for nondegeneracy. Degenerate profiles form a meagre subset of the complete metric space of \emph{admissible} attitude
profiles (\eqref{eq:AL} with the attitude boundary conditions, sup metric).\Srep\
\Sleanpart{under \lean{PMPConclusion}; constant-mass parts; analytic and meagre criteria not formalized}
\end{theorem}
The meagreness claim must be made in the admissible class, not in $C^0([0,t_f];\Sph)$, where the admissible class is itself
nowhere dense. The proof runs in that class, because piecewise constant-speed geodesic interpolants (with short out-and-back
arcs where needed) are dense in it and are nondegenerate. With velocity constraints (e.g.\ a speed limit) the adjoint $\lambda_v$
can carry a measure part. The pointwise statement of \cref{thm:CS} still holds a.e., but the affine primer and the gnomonic
structure apply only on open intervals where every state constraint is inactive.
The result is sharp. For a fixed upright cone and a vertical descent at a suitable altitude, an interior-point solver
returns a lossy relaxed optimum with all lossy nodes at minimum throttle. A one-step ``purification'' SOCP repairs it
(Claims C-X, C-K; discrete version: at most three lossy nodes without state constraints, Lean
\lean{purification\_three}). So \emph{the relaxation itself is never the problem}. This agrees with the lossiness observed in
stored GTPL solutions (296~N delivered on a 400~N minimum-throttle arc).

\subsection{Per-instance exactness and the union structure}
\begin{theorem}[Theorem C-U, no path constraints {\pnote{math/04 \S9}}]\label{thm:CU}
% CLAIMS: C-U (CONFIRMED by verify-pos6; stated without path constraints) | Lean: none
Without path (state) constraints, $\Ft=\bigcup_{b}F_{t_f}(b)$ with each $F_{t_f}(b)$ convex (M1 with constant or convexified mass; PT by \cref{thm:C6}), and
$V(\theta)=\min_bV(b;\theta)$. In M1 with constant mass the 5-DOF minimum is attained, and the convex program at an optimal
attitude $b^*$ is exact for that instance.\Sproved
\end{theorem}
The impossibility theorems say exactly that this union of convex sets is not convex. \emph{All} of the nonconvexity lies
in the map $\theta\mapsto b^*(\theta)$.

\subsection{Pure TVC: exactly convex given the attitude}
\begin{theorem}[Theorem C-6 {\pnote{math/04 \S8}}]\label{thm:C6}
% CLAIMS: C-6 (registry: FORMALIZED, constant mass, closed-form dynamics) | Lean: throttle_interval, gimbal_bound_iff_cot, convex_tvcSet (Positive/TVC.lean), convex_feasData_M3b (Positive/Convexity.lean); torque_balance_iff not joined to the convexity theorem
In model PT with zero roll rate and constant mass, Euler's equation is equivalent to $\Pi_bT=-k\Pi_b\ddot b$, $k=J_\perp/L$,
$\Pi_b=I-bb^\top$. For a fixed $b\in W^{2,\infty}$, write $F=-k\Pi_b\ddot b$, $\varkappa=\norm F$. The exact 6-DOF problem is the
scalar-throttle program
\[
\min\int\sqrt{T_a^2+\varkappa^2}\quad\text{s.t.}\quad \ddot r=(T_ab+F)/m+g,\quad
\max\{\varkappa\cot\delta,\sqrt{(\rho_1^2-\varkappa^2)_+}\}\le T_a\le\sqrt{\rho_2^2-\varkappa^2},
\]
which is convex. No relaxation is involved. Consequently $F^{PT}_{t_f}(b)$ is convex for every attitude profile. If the body is
held upright ($b\equiv\ez$), then $T\parallel\ez$: the effective cone is $0$, so the common ``upright body with a $15^\circ$
pointing cone'' 3-DOF model is not 6-DOF-feasible for any off-vertical thrust.\Sleanpart{constant mass; torque balance and convexity joined in prose}
\end{theorem}

\subsection{Exact subclasses of the uniform problem}
\begin{proposition}[X5: small pointing cone, M1 only {\pnote{math/redteam-reform \S3.1}}]\label{prop:X5}
% CLAIMS: X5, RR-P (verify-pos6: NEEDS FIX, missing hypothesis omega tf >= angle(b0,bf) added here) | Lean: none
In M1 with an LCvx pointing constraint $\angle(d,\ez)\le\theta_p$: if $\theta_p\le\delta$ and the initial (and, if prescribed,
terminal) attitude lie within $\delta-\theta_p$ of $\ez$, and, if the terminal attitude $b_f$ is prescribed,
$\omega t_f\ge\angle(b_0,b_f)$ (automatic for $b_0=b_f=\ez$), then $F_{5\mathrm{DOF}}=F_{3\mathrm{DOF}}(\theta_p)$, so classical LCvx guarantees
transfer verbatim. If $\theta_p>\delta$ (and the B$^*$ braking condition holds), $\Ft$ is nonconvex. Thus $\theta_p=\delta$ is a sharp
threshold \emph{for M1}.\Srep
\end{proposition}
X5 relies on the gimbal pointing the thrust while the body stays still, which is impossible on a pure-TVC vehicle
(\cref{thm:C6}). There the effective exact class collapses to $\theta_p=0$. More precisely, a prescribed planar thrust history
with $\norm T\ge\rho_1$, an initial axis $b_0$ in the plane and an in-plane initial body rate, is exactly TVC-realizable only for
rates in an interval of length at most $2\delta\mu_c/\sinh(\mu_ct_f)$, $\mu_c^2=L\rho_1\cos\delta/J_\perp$. For our vehicle at $t_f=7$~s
this is $3.5\times10^{-6}$~rad/s at $\rho_1=400$~N ($1.8\times10^{-5}$~rad/s at the flight-code value $\rho_1=300$~N). So a 3-DOF
LCvx optimum is essentially never exactly 6-DOF-optimal (Claim C-Y, \Sproved). In M1, by contrast, $V_5=V_3$ iff some
3-DOF optimum is $\delta$-trackable by an admissible attitude, with a closed-form primer-arc certificate (Claim C-3D)\Spending.

\subsection{Semidefinite lifts}\label{sec:sdp}
Occupation-measure linear programs with point-mass data entry are exact but infinite-dimensional and per instance
(\cref{sec:scope}). Their order-one truncation is exactly the affine case of Theorem A. The first nontrivial tractable
truncation is the degree-2 (Shor) lift \cite{shor1987,lasserre2001siopt}. We study it for the fixed-thrust
minimum-landing-error problem. With weights $c^v_k,c^r_k$, unknown unit vectors $b_k$ (axis) and $d_k$ (thrust direction),
inner-product constraints $\ip{d_k}{b_k},\ip{d_k}{b_{k+1}}\ge\cos\delta$ (gimbal) and $\ip{b_k}{b_{k+1}}\ge\cos\omega h$ (rate), and
cost $\norm{\sum c^v_kd_k-w_v}^2+\norm{\sum c^r_kd_k-w_r}^2$, the problem is a vector QCQP. The data $w$ enter only the
objective, and the lifted cost is a second-moment cost. The lift therefore lies outside the classes of Theorems A and D, and
no contradiction arises.

\begin{lemma}[Shor lift = Hilbert-sphere problem {\pnote{math/08 Lemma~1.1}}]\label{lem:shor}
% CLAIMS: L-SD2 (lemma part, not disputed), SDP-T1 context (CONFIRMED by verify-pos6) | Lean: none
The Shor relaxation's value equals the minimum of the same vector QCQP posed in $\R^{3+m}$ (indeed in any real Hilbert space
containing $\R^3$). The lift is exact iff some optimum can be ``planarized'' into $\R^3$.\Sproved
\end{lemma}
\begin{theorem}[Stress certificate and local-to-global {\pnote{math/08 Thms~2.1, 2.4}}]\label{thm:stress}
% CLAIMS: SDP-T1, SDP-T4 (CONFIRMED by verify-pos6) | Lean: none
Let $z^*$ be a genuine KKT point with multipliers $(\lambda,\mu)$ and stress matrix
$Q_\lambda=C+\mathrm{diag}(\mu)-\tfrac12\sum_e\lambda_e(E_{ij}+E_{ji})$. If $Q_\lambda\succeq0$, then $z^*$ is a global optimum of the lift
in every dimension, hence of the genuine problem. Conversely, exactness implies that a PSD stress exists, and
$Q_\lambda\succ0$ gives a unique rank-3 optimum. Moreover the lift is exact iff some genuine global minimizer is a \emph{local}
minimizer of the problem posed in $\R^4$ (``$\Leftarrow$'' under LICQ). Any LICQ KKT point that is a local minimizer in $\R^4$ is
a global minimizer of the lift.\Sproved
\end{theorem}
\begin{theorem}[Coplanar data: certified global optima {\pnote{math/08 Thm~4.1}}]\label{thm:coplanar}
% CLAIMS: SDP-P (verify-pos6: CONFIRMED without state constraints and with Gram-linear ones; glide-slope clause removed here) | Lean: none
If the lateral parts of $w_v$ and $w_r$ are parallel (velocity-only, position-only or vertical-plane targets), then every
planar genuine local minimizer satisfying LICQ is a certified global optimum of both the lift and the genuine problem. This
remains true with additional constraints that are linear in the Gram matrix, e.g.\ altitude $\ip{r_j}{\ez}\ge0$ at the nodes.\Srep
\end{theorem}
A glide-slope constraint is not linear in the Gram matrix (it involves squares of first moments), and the proof does not
extend to it. With a glide slope, exactness must be checked a~posteriori by the stress test of \cref{thm:stress}; an a~priori
statement is open. A structural fact about lifted optima also holds: under rate saturation with nondegenerate multipliers, every
lifted KKT configuration lies in $\mathrm{span}(\ez,b_1,y_v,y_r)$, and since the target subspace $E_w=\mathrm{span}(\ez,w_v,w_r)$ is
contained in that span, the lifted optimum has rank $\le4$ when the target data span three dimensions ($\le5$ for coplanar data)
\pnote{math/08 Prop.~5.1, with the step added by verify-pos6}\Srep.

\noindent\emph{Where exactness fails} (all \Snum\ unless marked).
\begin{itemize}[leftmargin=*,itemsep=2pt]
\item \emph{Unit-thrust discretization with gimbal.} With $\norm{d_k}=1$ and $\delta>0$ the lift is lossy. On an asymmetric
near-dent target the SDP gives $0.027529$ (rank 4), against a best genuine value of $0.028231$ over about 1{,}000 diverse runs, a
2.5\% gap. Three independent implementations agree, and an explicit feasible $\R^4$ chain attains the SDP value. At small $N$
the gap is certified by order-2 Lasserre bounds, up to solver accuracy (e.g.\ $N=3$, $\delta=15^\circ$: Shor $1.862$ against Lasserre-2
$2.358\approx$ genuine $2.357$). A plausible mechanism is identified: the lifted gimbal lens is exactly the convex hull of the genuine
lens \pnote{math/08 Prop.~6.1; refereed}, so in the lift $d_k$ can tilt into the extra dimension at no rate cost and shorten its
in-plane part. A unit-norm discretization forbids this, while relaxed controls in continuous time allow it. With the
convexified lens ($\norm{d_k}\le1$) the same instances are exact numerically.
\item \emph{Variable throttle.} Every degree-2 throttle lift tested is lossy. For the natural lift with $\norm{U_k}^2=a_k^2$, the gap at
fixed physics grows with the discretization: 12\%, 40\%, 54\%, 63\% and 68\% at $N=4,6,8,12,16$. The lift tends to the
no-rate-limit value, so the gap is not a discretization artifact. At $N=3$ an order-2 Lasserre bound equals the local optimum
$0.6047$ while the Shor value is $0.5759$ \stag{Plum}{certified numerically by Lasserre-2, up to solver accuracy}. The separate-axis
lift CSD3 is also lossy, by 2--35\% even with $\delta=0$.
\item \emph{Path constraints.} An altitude constraint stayed exact in every active scenario. A glide-slope constraint broke exactness
in 1 of 8 active scenarios (1.19\%, rank 4) even with $\delta=0$, consistent with the restriction of \cref{thm:coplanar} to
Gram-linear constraints.
\item \emph{$\delta=0$ (no gimbal), no path constraints.} No gap on about 2{,}900 targets.
\end{itemize}

\begin{conjecture}[CSD2$'$]\label{conj:csd2p}
% CLAIMS: CSD2' (OPEN, unbroken: ~4,500 solves, 0 gaps on 509 former unit-d gap instances); partial results CSD2'-T1..T5, P6, P7 refereed by verify-sdp2 (no BROKEN)
For fixed thrust and no path constraints, the Shor lift of the minimum-landing-error problem is exact in each of three
settings: (a) in continuous time, with relaxed thrust direction $u(t)\in\conv\,\mathrm{cap}(b(t),\delta)$ and a rate-limited axis;
(b) for the convexified-lens discretization $\norm{d_k}\le1$; and (c) for the $\delta=0$ chain.\Sopen
\end{conjecture}
No counterexample is known. About 4{,}500 solves were run, including zero gaps on all 509 instances that were gaps for the
unit-norm discretization once convexified. The following partial results were refereed independently
\pnote{math/09; math/verify-sdp2-report.md}:
\begin{itemize}[leftmargin=*,itemsep=2pt]
\item \emph{T1 (alignment).} The lifted value is an infimum over lifted trajectories whose physical readout lies in $\R^3$. Hence the
conjecture for all targets is equivalent to $R_X\cap(\R^3)^2=R_3$: every lifted trajectory that lands in $\R^3$ can be replaced by a
3-D one with the same terminal state. \Sproved
\item \emph{T2 (primer-plane fold).} The lift is exact for \emph{every linear objective of the terminal readout} $(V,R)$, in continuous
time and in all three discretizations. This closes the support-function question left open in math/08 (it does not cover
attitude-dependent linear costs). \Sproved
\item \emph{T3--T4 (stress certificate and hemisphere/Picone theorem).} The continuous-time version holds given a normal KKT
multiplier set, which is automatic with free terminal attitude but not with prescribed terminal attitude. The discrete
version (convexified lens, $\delta=0$) is fully rigorous, and its proof uses exactly the sign $\mu_d\ge0$ that the convexified lens
provides. An a~priori class follows: targets whose vertical demand exceeds full upright thrust, with $\omega t_f<\pi$, given
the multiplier hypothesis. \Srep
\item \emph{T5 (index identity).} At a genuine KKT point satisfying nondegeneracy hypotheses,
$\mathrm{neg}(Q)=\mathrm{neg}(Z)-p_0(C_{yw})$. Here $Z$ is the cable part of the stress, and $p_0$ is the number of nonnegative eigenvalues of
the $2\times2$ lateral residual/target covariance. With free terminal attitude, $\mathrm{neg}(Z)$ equals the number $k$ of crossings
of the primer plane, so the lift is exact iff $k\le p_0$. With upright terminal attitude, one residual case $k=p_0+1$ remains, and
the conjecture reduces to an integer equality there (Conjecture CSD2$''$). \Srep\ \emph{Caveat:} the nondegeneracy hypotheses hold at
only a minority of computed optima (188 of 898 in fresh banks; 9 of 17 earlier test cases). The direct stress test of
\cref{thm:stress} certifies all 17.
\item \emph{P6, P7.} Genuine local optima have no free singular arcs, so the lens-hull mechanism of the unit-norm failure has no
continuous-time analogue at genuine optima. The unit-norm failure goes with negative norm multipliers $\mu_d<0$, which the
convexified lens excludes (mechanism proved; correlation numerical). \Sproved
\end{itemize}
\emph{Physical meaning of an exact relaxed optimum.} The certified 3-D optimum has a genuine rate-limited attitude $b(t)$. Its
thrust direction is relaxed, $u(t)\in\conv\,\mathrm{cap}(b(t),\delta)$. By Aumann's theorem there is a measurable full-thrust direction
selection in the cap, with the same $b$, that reaches \emph{exactly} the same terminal state. This selection generally chatters,
so it assumes unlimited gimbal bandwidth. It is not a saturated $\pm\delta$ law.

\emph{Open problem (CSD2$''$).} What remains of the conjecture is a residual class of genuine optima with prescribed (upright)
terminal attitude and exactly $k=p_0+1$ crossings of the primer plane. There the index identity leaves a single integer equality
undecided. With free terminal attitude, T5 decides exactness under its nondegeneracy hypotheses. Also open is the continuous-time
normality step for prescribed terminal attitude, which T3/T4 assume. No proof attempt is currently active.

\emph{Practical reading.} The degree-2 lift is a polynomial-size SDP whose value is always a rigorous lower bound, and a
positive value certifies that exact landing is infeasible. Exactness is certified a~posteriori by a rank-3 optimum, by the
stress test of \cref{thm:stress}, a~priori in the coplanar case of \cref{thm:coplanar}, or (for every linear objective of the
terminal readout) by T2. In the tests, it was exact on every realistic in-air target for our vehicle. It is a certificate, not a lossless convexification. It does not handle minimum
fuel: fuel is constant for fixed thrust, and the natural variable-throttle lift is lossy.
